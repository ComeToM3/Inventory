## 3. Modèle retenu

- Quatre états `StockLevel` : `full=4`, `half=2`, `quarter=1`, `empty=0`, stockés dans `nodes.quantity`.
- Labels UI : `1`, `½`, `¼`, `0`.
- Cycle : `next` → 1 → ½ → ¼ → 0 → 1.
- `stock_reference` facultatif (entier ≥ 1), fiche seulement.
- Sentinel interne `stock_unit = 'niveau'` pour conserver les CHECK NOT NULL existants ; jamais affiché.
- `unit_cost_cents` non exposé ; mis à NULL à la création / mise à jour produit.

## 4. Éléments retirés de l’interface

- Unités de référence (presets / personnalisé).
- Coût par unité.
- Fractions / quarts à la création.
- Feuilles Approvisionner / Consommer / Corriger.
- Affichage du solde en quarts dans le sous-titre de ligne.

Conservé : nom, parent, quantité de référence facultative, Historique, Supprimer (mode modification).

## 5. Fonctionnement du cercle

- Zone C de la ligne produit Stock (colonne d’actions, à gauche de l’emplacement du `+` des parents).
- Visible uniquement pour les produits Stock (`space=stock` + `item`).
- Emplacements / contenants : `+ Ajouter` inchangé.
- Tap unique → `cycleStockLevel` → UI immédiate + persistance + ledger.

## 6. Persistance

- Schéma **v7** : colonne `stock_reference` ; CHECK création : `quantity IN (0,1,2,4)` pour produits Stock.
- API : `createNode` démarre à `full` ; `cycleStockLevel` / `setStockLevel` ; `updateStockProduct(name, parent, stockReference)`.

## 7. Compatibilité des données existantes

Migration `_migrateToV7` déterministe :

| Ancien `quantity` | Nouvel état |
| --- | --- |
| ≤ 0 | 0 |
| 1 | ¼ |
| 2 ou 3 | ½ |
| ≥ 4 | 1 |

Puis `unit_cost_cents = NULL` et sentinel `stock_unit` si vide. Pas de drop destructif de colonnes.

## 8. Historique

- Ledger `stock_movements` réutilisé.
- Création : mouvement `initial` (niveau 1).
- Cycle : mouvement `correct` ; UI affiche `ancien → nouveau` + date.
- Pas d’obligation utilisateur d’utiliser approvisionnement/consommation en quarts.

## 10. Parcours réellement observés (émulateur)

1. Emplacement Stock `Cuisine` créé.
2. Produit `Cafe` créé sans fraction → cercle **1**.
3. Cycles observés : **1 → ½ → ¼ → 0 → 1**.
4. Produit `Huile` créé ; cycle indépendant → Cafe **½**, Huile **¼**.
5. `Ajouter dans Cuisine` toujours présent.
6. Fiche : quantité de référence facultative ; **aucune** unité / coût / Approvisionner.
7. Historique : `Création · 1` et `Changement de niveau · X → Y` + date.
8. Force-stop + relance : Cafe **½**, Huile **¼** conservés.
9. Biens : vide, inchangé / isolé.
10. À acheter : message « prochainement », isolé.
