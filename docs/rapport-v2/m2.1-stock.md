## 5–7. Modèle, quarts, unités

- Produit : `space=stock`, `node_type=item`, `stock_unit`, `quantity` = quarts ≥ 0, `unit_cost_cents` optionnel.
- Contenant Stock : `item_container` sans quantité.
- Affichage : `0,25` / `0,5` / `0,75` / entiers ; pièces en UI entière préférée.
- Unités préréglées + « Autre unité ».

## 8–12. Création, mouvements, atomicité, historique

- Création/modif Stock via formulaire existant branché sur l’espace.
- Solde modifié **uniquement** via `supply` / `consume` / `correct` (+ `initial` à la création si > 0).
- Refus consommation > solde (`insufficientStock`).
- Table `stock_movements` : type, delta, solde résultant, unité figée, horodatage.
- Historique Stock (menu) ≠ retraits Biens.
